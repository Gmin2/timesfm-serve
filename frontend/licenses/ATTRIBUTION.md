# UI Sources

- Evilcharts: selected chart container, table, tabs and select source from the
  locally supplied Evilcharts repository. Copyright 2026 Gurbinder, MIT;
  the complete notice is in `evilcharts.txt`.
- Tailark Quartz: `src/components/ui/button.tsx` started from the locally supplied
  `components/_primitives/button/button.tsx`; its variants have since been restyled.
  Theme tokens in `src/index.css` now follow `design/README.md`.
  Tailark's own license terms remain applicable; no MIT license is asserted for it.
- Interface Craft: the view transition's named timing and reduced-motion behavior
  follow the supplied Storyboard Animation guidance.
- Icons: interface icons in `src/components/icons.tsx` are converted from the local
  Nucleo `ui`, `core` and `social` collections, and `src/assets/github.svg` is copied
  from `social/logo-github.svg`. Nucleo's supplied license and GitHub's trademark
  terms remain applicable. `public/favicon.svg` still carries its Lucide notice.
- Font: Inter via Fontsource. Package license notices are
  retained with the installed dependencies.

No Bklit Studio, Flux, Liveline, or chart-gallery demonstration data is included.
